# Сборка Windows-дистрибутива

## Скачать готовую программу

1. Откройте [Windows build](https://github.com/deakatsuxq/ImageBoost-Pro/actions/workflows/windows-build.yml).
2. Выберите успешный запуск для нужного коммита. Внизу страницы, в **Artifacts**,
   скачайте `ImageBoostPro-Windows`. Для скачивания артефактов нужен вход в GitHub.
3. Распакуйте архив артефакта. В нём находятся `ImageBoostPro-Windows.zip` и
   `SHA256SUMS.txt` с SHA-256 контрольной суммой ZIP.
4. Распакуйте `ImageBoostPro-Windows.zip` в обычную доступную для записи папку.
5. Откройте `ImageBoostPro/ImageBoostPro.exe`. Python устанавливать не требуется.

Каталог `_internal` должен оставаться рядом с EXE. Перемещайте всю папку
`ImageBoostPro` целиком. Запускайте программу после распаковки.
Поддерживаемая целевая платформа — Windows 10/11 x64.
Артефакты сохраняются GitHub на 30 дней: позднее запустите сборку повторно.

Дистрибутив не подписан сертификатом издателя. Windows может показать предупреждение
SmartScreen: перед запуском проверьте репозиторий, коммит сборки и SHA-256 архива.
Это не проверка антивирусом и не замена проверке происхождения файла.

Проверить сумму в PowerShell:

```powershell
Get-FileHash .\ImageBoostPro-Windows.zip -Algorithm SHA256
```

## Запустить сборку вручную в GitHub

В разделе **Actions → Windows build → Run workflow** выберите ветку и нажмите
**Run workflow**. По умолчанию создаётся облегчённая сборка: все классические
алгоритмы работают на CPU, нейросетевые зависимости и веса не включаются.
Флажок **with_ai** включает дополнительные Python-зависимости и существенно
увеличивает размер ZIP и время сборки. Веса подключаются отдельно.

Workflow находится в `.github/workflows/windows-build.yml`. Он работает на
`windows-latest` с Python 3.11 x64 и выполняет:

1. Установку зависимостей из закреплённых `requirements*.txt` и `pip check`.
2. Проверку `ruff` и автоматические тесты, включая виджеты Qt с `offscreen`.
3. PyInstaller `onedir` по `ImageBoostPro.spec`; UPX и режим `onefile` не используются.
4. Запуск собранного EXE с настоящим Windows-плагином Qt: чтение изображения,
   анализ, обработка, экспорт, создание окна и отрисовка.
5. Создание ZIP, распаковку в другую папку и повторный запуск EXE из распакованного ZIP.
6. Публикацию дистрибутива только после успешных проверок.

Второй артефакт `ImageBoostPro-Windows-checks` содержит JSON-отчёты, изображения
проверки и предупреждения PyInstaller. При ошибке сборка становится красной;
артефакт программы для этого запуска не публикуется. Журнал шага показывает
конкретную ошибку. Перед выдачей Windows-версии пользователю нужно убедиться,
что запуск для соответствующего коммита зелёный.

## Собрать локально на Windows

Нужны Git и Python 3.11 x64 с доступной командой `python`.
В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
.\scripts\build_windows.ps1
```

Или после активации окружения запустите `scripts\build_windows.bat` из `cmd`.
Скрипт сам устанавливает зависимости, проверяет их, запускает тесты, собирает
приложение и проверяет EXE до и после упаковки. Результат:
`dist\ImageBoostPro-Windows.zip`. Для повторной сборки с уже установленными
зависимостями можно передать `-SkipDependencyInstall`.

Расширенный вариант:

```powershell
.\scripts\build_windows.ps1 -WithAI
```

Сборку Windows следует выполнять на Windows: PyInstaller не создаёт Windows EXE
из Linux. Linux CI проверяет исходное приложение и алгоритмы отдельно.
Модели Real-ESRGAN могут требовать много RAM/VRAM; расширенная сборка по умолчанию
использует доступный бэкенд PyTorch. CUDA требует совместимого GPU, драйвера и
сборки PyTorch. Облегчённая сборка работает без этих компонентов.

## Диагностика

* Убедитесь, что вся папка `_internal` распакована вместе с EXE.
* Не переносите EXE отдельно и не запускайте его внутри ZIP.
* Отчёты smoke-проверок находятся в `reports/` машины сборки и артефакте проверок.
* В консоли разработчика можно запустить:

  ```powershell
  $process = Start-Process .\dist\ImageBoostPro\ImageBoostPro.exe -Wait -PassThru `
    -ArgumentList '--smoke-test --smoke-output "C:\Temp\imageboost-smoke.json"'
  $process.ExitCode
  Get-Content C:\Temp\imageboost-smoke.json
  ```

Smoke-проверка не заменяет ручную оценку визуального качества фотографий,
тестирование видеодрайверов и масштабирования интерфейса на реальных ПК.
