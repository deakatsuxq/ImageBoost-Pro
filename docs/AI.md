# Нейросетевое увеличение

## Что реализовано

AI-модуль выполняет настоящую inference RRDBNet с совместимыми весами Real-ESRGAN
на PyTorch. Интерполяционные алгоритмы находятся в отдельной категории.
Если PyTorch или нужная модель отсутствуют, появляется объяснимая ошибка;
подмена нейросети обычным масштабированием не выполняется.

Поддерживаются официальные архитектуры:

| Ключ | Модель | Нативный масштаб |
|---|---|---|
| `realesrgan-x2plus` | RealESRGAN_x2plus | ×2 |
| `realesrgan-x4plus` | RealESRGAN_x4plus | ×4 |
| `realesrgan-anime-6b` | RealESRGAN_x4plus_anime_6B | ×4 |

Архитектура считывается из размеров тензоров checkpoint и проверяется перед
использованием. Это проверка совместимости, а не доказательство качества весов
или подлинности их происхождения. Код приложения не использует произвольную
десериализацию pickle как запасной путь.

GFPGAN, восстановление лиц и BM3D не входят в эту версию. AI не гарантирует
достоверного восстановления отсутствующих деталей: результат может содержать
синтезированные текстуры. Сравнивайте его с оригиналом.

## Установка и модели

В исходном виртуальном окружении:

```bash
python -m pip install -r requirements-ai.txt
```

Базовый ZIP для Windows не включает PyTorch. Для него выберите
**Actions → Windows build → Run workflow → with_ai** либо соберите программу
из исходников с `scripts/build_windows.ps1 -WithAI`.
Веса не включены ни в облегчённую, ни в расширенную сборку.

Добавьте совместимый локальный `.pth` в выбранную папку моделей через интерфейс
настроек и укажите путь к модели в инструменте увеличения.
Для программной работы доступен менеджер:

```python
from imageboost_pro.ai import ModelManager, runtime_status

print(runtime_status())
manager = ModelManager()  # стандартная пользовательская папка моделей
print(manager.list_models())

# Отдельное явное действие: скачивание официальных весов по HTTPS.
# Весовой файл занимает десятки мегабайт; дождитесь завершения загрузки.
path = manager.download_model("realesrgan-x2plus")
print(path)
print(manager.sha256_file(path))
```

Менеджер загружает модели только по явному запросу, использует официальные
release-ресурсы GitHub и проверяет структуру весов. Официальный реестр текущих
моделей не публикует SHA-256 для этих ресурсов: вычисленная локальная сумма
помогает сравнивать копии, но сама по себе не подтверждает источник.
Если у вас есть опубликованная автором контрольная сумма, сверяйте её отдельно.
После установки зависимостей и весов обработка работает без интернета.

Источники весов и описания моделей:
[Real-ESRGAN releases](https://github.com/xinntao/Real-ESRGAN/releases).

## CPU, CUDA и память

Выбор `auto` использует доступное устройство; `cpu` работает без видеокарты,
`cuda` требует совместимых NVIDIA GPU, драйвера и сборки PyTorch с CUDA.
Определение наличия CUDA не заменяет реальный тест на конкретном GPU.
Инструкции установки совместимой сборки PyTorch:
[официальный установщик](https://pytorch.org/get-started/locally/).

Обработка разбивается на блоки с перекрытием по рецептивному полю модели.
Меньший блок снижает пиковые требования к памяти, увеличивая время вычислений.
При ×8 модель применяется последовательно; для ненативного масштаба результат
настоящей inference доводится до нужного размера Lanczos. Это явно отличается
от получения всего результата одной интерполяцией.
Промежуточный результат ограничен 64 Мп; слишком большие запросы отклоняются
с сообщением об ошибке, а не приводят к намеренному исчерпанию памяти.

На CPU большие фотографии могут обрабатываться долго. Начните с небольшой
фотографии и ×2. Веса и промежуточные тензоры занимают дополнительную RAM/VRAM.
Проверки доступности зависимостей и формы тензоров не подтверждают качество
обученной модели. Реально выполненные проверки и ограничения оборудования
указываются отдельно в [VALIDATION.md](VALIDATION.md).

В облачной Linux-среде проверена настоящая CPU inference официальных весов
`RealESRGAN_x2plus.pth`: фотография 32×24 преобразована в 64×48;
отдельно проверен ×8 тремя последовательными проходами. Полученный результат
отличается от Lanczos. Это подтверждает выполнение нейросетевого конвейера,
но не является оценкой визуального качества модели на полном наборе фотографий.
Также выполнены настоящие CPU-проходы официальных `RealESRGAN_x4plus.pth` и
`RealESRGAN_x4plus_anime_6B.pth`: вход 5×6, выход 20×24 RGB uint8.
CUDA в этой среде отсутствует и не проверялась.
