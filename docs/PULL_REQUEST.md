ImageBoost Pro превращает пустой репозиторий в рабочий русскоязычный настольный редактор.
Пользователь открывает фотографию, получает измеряемый анализ качества, применяет реальные
алгоритмы, сравнивает оригинал с результатом и сохраняет обработку из исходного разрешения.

Реализованы интерактивное сравнение, ночное восстановление (Gamma/CLAHE/Retinex),
интерполяция, пять видов шумоподавления, резкость, цветокоррекция, JSON-пресеты,
история параметров и пакетный экспорт с отменой и продолжением после ошибки файла.
Real-ESRGAN использует настоящие локальные веса, CPU/CUDA и обработку блоками.
Отсутствующие зависимости или веса приводят к явной ошибке; обычный resize не выдаётся за AI.
GFPGAN и BM3D в эту версию не включены.

Windows workflow на `windows-latest` / Python 3.11 собирает PyInstaller `onedir`,
проверяет EXE до упаковки и после распаковки ZIP. Включён `workflow_dispatch`.
Артефакт: **ImageBoostPro-Windows**, запуск: `ImageBoostPro/ImageBoostPro.exe`.
