# ImageBoost Pro

Русскоязычный настольный редактор фотографий на Python, PySide6 и OpenCV.
Классическая обработка работает локально на CPU и не требует интернета.
Нейросетевые функции подключаются отдельно: обычная интерполяция не выдаётся за AI.

## Скачать и запустить на Windows 10/11

Откройте [Actions → Windows build](https://github.com/deakatsuxq/ImageBoost-Pro/actions/workflows/windows-build.yml),
выберите успешный запуск для нужного коммита и скачайте артефакт
**ImageBoostPro-Windows**. Внутри находятся `ImageBoostPro-Windows.zip` и его SHA-256.
Распакуйте ZIP целиком и запустите **`ImageBoostPro/ImageBoostPro.exe`**.
Установка Python не нужна. Папка `_internal` должна оставаться рядом с EXE.

Проверенная версия с ретушью по маске: **[успешная сборка 9b69695](https://github.com/deakatsuxq/ImageBoost-Pro/actions/runs/39146445334)**.

Если успешного запуска ещё нет, нажмите **Run workflow**. Наличие исходников
и workflow само по себе не подтверждает готовность Windows-дистрибутива:
обязателен зелёный запуск со smoke-проверкой собранного EXE и распакованного ZIP.
Артефакт доступен 30 дней; для скачивания нужен вход в GitHub.
Для ручного запуска новой сборки через `workflow_dispatch` workflow должен быть
в основной ветке `main`; текущая сборка ветки разработки уже доступна по ссылке выше.
Подробные действия: [сборка и диагностика](docs/BUILD.md).

## Возможности

* Интерактивное сравнение «До / После»: перетаскиваемый разделитель, вид бок о бок,
  удержание оригинала, общий масштаб и перемещение даже при разных разрешениях.
* Ночное восстановление: гамма, CLAHE, Retinex, шумоподавление, защита ярких источников
  света и три пресета от мягкого до максимального осветления.
* Анализ качества: яркость, тени и пересвет, контраст, оценка шума и размытия,
  цветовой сдвиг, признаки JPEG-артефактов и рекомендации по обработке.
* Увеличение и уменьшение: Nearest, Bilinear, Bicubic, Lanczos, Area;
  масштабы 1.5×–8× и произвольный размер с сохранением пропорций.
* Шумоподавление: Gaussian, Median, Bilateral, Non-Local Means и Wavelet.
* Резкость: Unsharp Mask, High-Pass, Laplacian и адаптивное усиление;
  локальный контраст, экспозиция, цвет и восстановление освещения.
* Ручная ретушь царапин и пятен: кисть в координатах оригинала, история мазков,
  настоящее OpenCV Inpainting (Telea / Навье — Стокс), сравнение и сохранение новой копии.
* Неразрушающие настройки, отмена и повтор, встроенные и пользовательские JSON-пресеты,
  пакетная обработка с продолжением после ошибки отдельного файла.
* Экспорт JPG/JPEG, PNG, WebP, BMP, TIFF; настройка качества, прозрачность,
  EXIF-ориентация, доступные метаданные и ICC-профиль.
* Необязательная настоящая Real-ESRGAN inference с локальными весами, CPU/CUDA
  и разбиением на блоки. GFPGAN в текущую версию не входит.

Оценки качества — вычисляемые эвристики, а не достоверное определение содержания
фотографии. Ночное восстановление улучшает доступный сигнал; полностью утраченные
детали не восстанавливаются достоверно. Нейросеть может создавать правдоподобные
детали, которых не было в оригинале.

## Как пользоваться

1. Нажмите **Открыть** или перетащите фотографии в окно. Выберите изображение слева.
2. Запустите анализ и изучите рекомендации. Выберите встроенный пресет,
   режим автоматического улучшения или настройте инструменты справа.
3. Предпросмотр обновляется в фоне после изменения параметров. Он использует
   уменьшенную копию; полный результат вычисляется из оригинала при обработке и экспорте.
4. Сравните результат разделителем или режимом «Бок о бок», увеличьте колёсиком
   и переместите изображение мышью. Кнопка оригинала показывает его при удержании.
5. Нажмите **Улучшить изображение**, затем **Сохранить** и выберите формат и качество.
   Подтвердите перезапись, если файл уже существует.
6. Для серии снимков добавьте файлы или папку, задайте общие настройки,
   выберите выходную папку и запустите очередь.
7. Для повреждений выберите **Обработка → Ретушь по маске** (`Ctrl+Shift+R`).
   Закрасьте небольшой дефект, нажмите **Восстановить**, сравните и сохраните копию.
   Колесо меняет масштаб, правая кнопка перемещает изображение. Ретушь работает
   с оригиналом отдельно от эффектов; сохранённая копия добавляется в список фотографий.

## Запуск из исходников

Рекомендуется Python 3.11 x64. В Linux для графического запуска нужен рабочий Qt/desktop;
для автоматических проверок используется `QT_QPA_PLATFORM=offscreen`.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python main.py
```

Зависимости закреплены в `requirements.txt`, инструменты разработки — в
`requirements-dev.txt`. Базовый запуск не импортирует PyTorch и не загружает модели.

## Нейросети

В исходном окружении установите дополнительные зависимости:

```bash
python -m pip install -r requirements-ai.txt
```

Затем подключите совместимые локальные веса через настройки моделей.
Используйте официальные источники и контрольную сумму, если она опубликована.
Без зависимостей или нужных весов AI выдаёт объяснимую ошибку; классическая обработка
продолжает работать. Облегчённый EXE не включает PyTorch: для AI используйте исходники
или сборку **Run workflow → with_ai**. Установка `pip` рядом с готовым облегчённым EXE
не добавляет библиотеки внутрь его изолированной поставки.

Информация о моделях и ограничениях: [AI-модуль](docs/AI.md).

## Проверки

```bash
python -m pip check
python -m ruff check .
QT_QPA_PLATFORM=offscreen python -m pytest -q
QT_QPA_PLATFORM=offscreen python main.py --smoke-test --smoke-output reports/source-smoke.json
```

В PowerShell задайте `$env:QT_QPA_PLATFORM = 'offscreen'` отдельной командой.
Smoke-проверка создаёт настоящее окно Qt, обрабатывает тестовое изображение,
сохраняет и читает результат и записывает JSON-отчёт; при ошибке возвращается
ненулевой код. Windows CI дополнительно запускает уже собранный EXE с Windows-плагином Qt
до упаковки и после распаковки ZIP. Отчёт о выполненных проверках находится
в [docs/VALIDATION.md](docs/VALIDATION.md), текущие результаты — в Actions.
